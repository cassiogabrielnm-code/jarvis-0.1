# JARVIS 0.1 🤖

Primeira versão do assistente pessoal Android.

## Comandos disponíveis

- "Que horas são?"
- "Abrir calculadora"
- "Abrir YouTube"
- "Quanto está a bateria?"
- "Abrir configurações"

Também existe um botão para iniciar o reconhecimento de voz.

## Como abrir

1. Abra este projeto no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Conecte um celular Android ou use um emulador.
4. Execute o app.
5. Conceda a permissão de microfone quando solicitada.
6. Toque em "Falar com JARVIS" e diga um dos comandos.
